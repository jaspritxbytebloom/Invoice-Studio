# 📖 About

Invoice Studio is a modern Invoice & Billing Management System developed for freelancers, agencies, consultants, startups, and small businesses.

The application simplifies invoice creation, client management, service management, payment tracking, and PDF document generation while providing a clean and responsive user experience.

This repository contains the **Community Edition**.

The **Pro Edition** includes advanced business features, premium support, and commercial licensing.

# ⚙ Installation

## Requirements

* PHP 8.0 or later
* MySQL 5.7+
* Apache / XAMPP / WAMP / LAMP
* Composer (Optional)

---

## Clone Repository

```bash
git clone git clone https://github.com/jaspritxbytebloom/Invoice-Studio.git
```

---

## Import Database

Import

```
database/invoice_studio.sql
```

using phpMyAdmin or MySQL Workbench.

---

## Configure Database

Edit

```
config/database.php
```

Update

```
Host

Database Name

Username

Password
```

---

## Launch

Place the project inside your web server directory.

Example

```
htdocs/invoice-studio
```

Visit

```
http://localhost/invoice-studio
```
