Invoice Studio
A web-based invoicing and business billing management application.

Invoice Studio is a web application designed to help businesses manage clients, invoices, services, payment records and invoicing-related reporting through a centralized interface.
Overview
Invoice Studio provides a centralized workspace for managing invoicing workflows, from client and service records to invoice creation, payment tracking and reporting.

This project is presented as a software portfolio showcase. The application source code is not distributed through this repository.
Features
- Dashboard — centralized overview of invoicing activity.
- Client Management — maintain client information and records.
- Invoice Management — create, organize and manage invoices.
- Service Catalog — maintain service-related billing information.
- Payment Tracking — manage and track invoice payment records.
- Payment Documentation — payment-related confirmation and receipt documentation.
- Reports — access invoicing and business reporting.
- Settings — manage application-related settings.
- Bank Account Settings — manage bank account information within the application.
Feature descriptions should be checked against the currently deployed application before this README is published.

Architecture Overview
Invoice Studio uses a server-side web application approach.
- Frontend: HTML, CSS, JavaScript and Bootstrap
- Backend: PHP
- Database: MySQL
- Web environment: Apache/PHP environment
